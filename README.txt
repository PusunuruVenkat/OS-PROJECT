======================================================================
  SWIFTSHARE - High-Concurrency File Distribution Server
======================================================================

HOW TO OPEN SWIFTSHARE (No Server / No Batch File Needed!):
-----------------------------------------------------------
👉 Just double-click "index.html" in this folder!

- Works standalone in any web browser (Brave, Chrome, Edge, Firefox).
- No terminal window, no batch files, and no background server required.
- Files you upload are saved in browser storage (IndexedDB) and persist across reopens.
- High-concurrency downloads, streaming simulation, search, and monitor work 100% locally.

FILES:
------
  - index.html, style.css, app.js : Full responsive application with IndexedDB engine
  - data/files.json             : Persistent metadata catalog
  - uploads/                    : Uploaded files directory
  - server.js                   : Optional Node.js backend
  - start-server.bat            : Optional Node launcher (only if you want CLI mode)
